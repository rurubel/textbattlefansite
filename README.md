# 텍스트배틀 팬사이트

정적 팬사이트 (HTML, CSS, Vanilla JS only)

## GitHub Pages 배포

1. 저장소 → Settings → Pages
2. Source: Deploy from a branch
3. Branch: main (또는 master) → / (root)
4. Save

배포 후: `https://<username>.github.io/textbattlefansite/`

## 로컬 실행

```bash
python3 -m http.server 8888
# http://localhost:8888
```
