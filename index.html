텍스트배틀이란?

  • 나만의 아이디어로 ai가 캐릭터를 만든다!
  • 내가 만든 캐릭터로 다른 캐릭터와 전투하는 AI 멀티 모달 캐릭터 PVP RPG 게임!
  • 지원 전투 : 1vs1, 3vs3, 보스전, 서버 통합 레이드

텍스트배틀 팬사이트 기능

  • 카드 성장 계산기 : 현재 부옵을 입력하면 이 카드가 목표 효율에 도달할 확률 계산
  • 애니 강화 시뮬레이터 : 일반 강화, 집중 강화로 30강 애니를 뽑는 시뮬레이터
  • 효율 계산기 : 카드 + 애니의 성능을 확인하는 지표인 효율을 계산
  • 선공 계산기 : 나와 상대 중 누가 선공인지 계산
  • 속성 계산기 : 속성 상성에 따른 평타 데미지·체력 보정값 계산
  • 포지션 성향 테스트 : 나에게 딱 맞는 포지션 추천
  • 카드 시뮬레이터 : 5성 카드를 뽑는 시뮬레이터
  • 개발자 캐릭터 소개 : 컨늅 패밀리 소개☺️

효율 계산기

효율: 0

효율 = 공×2 + 방×2 + 체

효율 80 ⬇️ 캐릭터의 기본 스펙이 낮습니다.

효율 81 ⬆️ ~ 100 ⬆️ 준수하지만 속공, 크리, 방부옵에 조금 많이 투자된 것 같습니다.

효율 101 ⬆️ ~ 120 ⬇️ 준수합니다.

효율 121 ⬆️ ~ 140 ⬇️ 꽤 높습니다.

효율 141 ⬆️ ~ 170 ⬇️ 깡스펙으로 이기는 판이 있을겁니다.

효율 171 ⬆️ 거진 신의 경지

포지션 별 효율 계산법은 차이가 있습니다.
