# 렙핑 계산기 구현 요약

## 목표
- 현재 캐릭터의 **레벨·누적 경험치**와 **일일 플레이 계획**을 입력하면, 목표 레벨(기본 80)까지의 **남은 경험치**, **예상 소요일**, **소비 티켓·던전 입장권** 등을 계산한다.
- 단순 `남은 경험치 ÷ 하루 경험치`가 아니라, **전투 → 경험치 → 레벨업 → 티켓 충전 → (옵션) 즉시 티켓 소비 → 추가 전투**를 반복하는 **이벤트 기반 시뮬레이션**이다.
- 레벨업으로 얻은 티켓을 육성에 다시 쓰는 경우와 **티켓작**(잉여 티켓으로 부캐 육성 → 순 티켓 회수)까지 같은 루프 안에 포함한다.

## 자원 가정 (확정)
| 자원 | 가정 |
|---|---|
| **티켓** | **무한정 보유**. 시뮬은 «소비 티켓»을 **누적 집계**만 한다. 일일 계획 판수대로 돌릴 때 **티켓 부족으로 중단하지 않는다**. |
| **던전 입장권** | **무한정 보유**. 조데헌·룬던은 사용자가 입력한 **하루 횟수**만큼 실행한다(입장권 고갈로 skip 하지 않음). 소비 입장권은 **집계용**. |
| **프리셋 «전부 X»** | **자원 무제한** 전제. 해당 콘텐츠만 사용해 **목표 레벨 도달까지** 투입(일일 cap 없음, 티켓/입장권 부족 없음). |

## 핵심 규칙
- 레벨 범위: 입력 **현재 레벨** ~ **목표 레벨**(드롭다운 `1~80`, 기본 `80`).
- 경험치는 **레벨별 필요량 테이블**(`LEVEL_XP_TO_NEXT`) 기준. 레벨 `L`에서 다음 레벨까지 필요량은 «`L+1`레벨» 행의 값(예: 41→42는 `2600`).
- **티켓 상한(충전 cap)**: 티켓 부스트 ON → `100`, OFF → `60`. 레벨업 시 **최대치까지 충전**(보유와 합산 후 상한 적용). *(보유는 무한이지만 충전 cap은 적용.)*
- **레벨업 티켓 지급(충전) 빈도**
  - 도달 레벨 **1~19**: **3의 배수 레벨**에 도달한 레벨업 때만 충전 (`3, 6, 9, 12, 15, 18`).
  - 도달 레벨 **20 이상**: **매 레벨업**마다 충전.
- **레벨업 티켓 사용** OFF: 레벨업 충전분을 시뮬레이션에서 쓰지 않음 + **티켓작 비활성**.
- **습던 특수**: 습던으로 **레벨업이 발생한 경우** 해당 레벨업에서는 **티켓 충전 없음**.  
  **레벨업 티켓 사용** ON이면, 레벨업 직전까지는 습던 가능하나 **마지막 필요 경험치는 반드시 테라 1판**으로 처리해 충전을 받도록 한다.
- **레벨업 후 즉시 티켓 소비**
  - **직접 입력**: 우선 **`terra`(테라)**.
  - **프리셋 «전부 X»**: 선택한 콘텐츠로만 소비 (예: 전부 1vs1 → 1vs1만). **예외: 전부 습던**은 충전·즉시 소비에 **테라** 사용.
- **프리셋 전부 1vs1** 고블린 (소비 티켓 기준 프로브 후 재시뮬)
  - **≤ 2400**: 고블린 **10~15마리** (XP `300~600`)
  - **> 2400**: 고블린 **15마리** (XP `300~600`)

## 콘텐츠 상수 (1회당 · 본캐 1명 기준)

| id | 이름 | 경험치 | 티켓 | 입장권 |
|---|---|---:|---:|---:|
| `pvp1` | 1vs1 | 30 | 6 | 0 |
| `terra` | 테라 | 50 | 10 | 0 |
| `jode` | 조데헌 | 600 | 10 | 1 |
| `habit` | 습던 | 120 | 20 | 0 |
| `rune` | 룬던 | **300** | 10 | 1 |

- 테라는 파티 3명이 경험치를 받지만, **본 계산기는 입력 캐릭터 1명분 경험치만** 누적한다.

## 레벨업 티켓 충전 요약표

| 도달 레벨 | 충전 여부 |
|---|:---:|
| 3, 6, 9, 12, 15, 18 | O |
| 1, 2, 4, 5, 7, 8, …, 17, 19 | X |
| 20 ~ 목표 레벨 | 매 레벨 O |

## 고블린 (1vs1 대체)
- 고블린은 **추가 보너스가 아니라 1vs1 판을 대체**한다.
- **일반 1vs1**: `30` XP / **`6` 티켓**
- **고블린 판**: `300 ~ 600` XP / **`6` 티켓** (1vs1과 동일)
- 일일 경험치: `(일반판 × 30) + (고블린판 × [300~600])` — `(총판 × 30) + 고블린` **아님**.
- **고블린 포함** 체크는 **1vs1 구간이 `0`이 아닐 때만** UI 표시.
- **고블린 계산 결과**: 평균이 아니라 **`최소 ~ 최대`** (일일 XP·소요일 모두).

### 1vs1 · 고블린 **범위 방식** (확정)

1. **일일 1vs1 판수** = 드롭다운 구간의 **min ~ max** (예: `0~50` → `0`판 ~ `50`판).
2. **고블린 마릿수** (같은 날): 판수를 **50으로 나눈 값**을 **0~5 스케일**로 매핑.

```js
/** pvpMin, pvpMax: 해당 구간 하한·상한 (예: 0~50 → 0, 50) */
function goblinCountRange(pvpMin, pvpMax) {
  const scale = (n) => Math.floor((n / 50) * 5);
  return { goblinMin: scale(pvpMin), goblinMax: scale(pvpMax) };
}
// 0~50 선택 → goblin 0 ~ 5
// 51~100 → 5 ~ 10
// 101~200 → 10 ~ 20
// … 동일 공식
```

3. **일일 1vs1 XP** (고블린 ON):

```text
pvpMinXp = (pvpMin - goblinMax) * 30 + goblinMin * 300
pvpMaxXp = (pvpMax - goblinMin) * 30 + goblinMax * 600
```

(판수·고블린 수가 음수가 되지 않도록 `Math.max(0, …)` 클램프.)

| 1vs1 구간 (하루) | 판수 min ~ max | 고블린 수 min ~ max (공식) |
|---|---|---|
| `0` | — | 고블린 UI 숨김 |
| `0~50` | 0 ~ 50 | 0 ~ 5 |
| `51~100` | 51 ~ 100 | 5 ~ 10 |
| `101~200` | 101 ~ 200 | 10 ~ 20 |
| `201~300` | 201 ~ 300 | 20 ~ 30 |
| `301~400` | 301 ~ 400 | 30 ~ 40 |

## 티켓작 (직접 입력 모드)
- **테라 던전**만으로 부캐를 **티켓작 종료 레벨**까지 키운다.
- **부캐와 본캐(육성 대상)는 같은 테라 판에 함께 들어간다.** 판마다 부캐·본캐 **둘 다 50 XP**를 받는다.
- **부캐는 항상 레벨 1**에서 시작.
- **회수 티켓** = 해당 사이클 시뮬 결과 **`(부캐 레벨업 충전으로 받은 티켓 합) − (해당 사이클 테라 소비 티켓 합)`** (사이클마다 계산).
  - 순 회수(`netTickets > 0`)분만 본캐 티켓 풀에 합류 후, 레벨업 티켓 사용 ON이면 즉시 테라로 재소비.
- **티켓작 종료 레벨**: 드롭다운 **`1~80`**, 기본 **`15`**.  
  - 낮은 레벨에서 끊는 이유: 종료 레벨이 높으면 «충전 티켓 − 육성 소비 티켓»이 **음수**가 되기 쉬워 **손해**이기 때문.
- **하루 티켓작 횟수**: 드롭다운 **`0~5`**, 기본 **`5`** (최대 5회).
- **레벨업 티켓 사용** OFF → 티켓작 **UI·로직 모두 비활성**.

## 플레이 방식 (UI)
- 라디오: **직접 입력(기본)** | 전부 조데헌 | 전부 습던 | 전부 테라 | 전부 룬던 | 전부 1vs1
- **직접 입력이 아니면** 티켓작·일일 횟수 입력란 **숨김**.
- **프리셋**: 해당 콘텐츠 **만** 사용, **목표 레벨까지** 반복(자원 무제한, 일일 입력 cap 없음).

## 예상 소요일 (확정)
- **기준**: 사용자 **하루 계획**(직접 입력) 또는 프리셋 단일 콘텐츠로 **하루에 얻는 경험치** + **레벨업·티켓 재투자·티켓작** 이벤트 시뮬.
- **티켓은 무한 보유**이므로 «티켓이 부족해 하루 계획을 못 채운다»는 가정 **하지 않음**. (표시되는 **소비 티켓**은 누적 비용.)
- **고블린·1vs1 구간** 등 범위가 있으면 소요일 **`최소 ~ 최대`**. 고블린 OFF·구간 없으면 단일값.

## 종료 조건
- `level >= targetLevel` (목표 레벨 **도달** 시 종료).
- 입력 검증 실패 시 계산하지 않음.

## 출력 항목 (최소)
| 항목 | 설명 |
|---|---|
| 남은 경험치 | 목표까지 필요 총 XP (입력 시점, 테이블 합산) |
| 예상 소요일 | **`최소 ~ 최대`** (범위 없으면 단일값) |
| 최종 소비 티켓 | 시뮬 전체 누적 (무한 보유 가정 하 **통계**) |
| 최종 소비 던전 입장권 | 조데헌 + 룬던 실행 횟수 기반 집계 |
| 총 레벨업 횟수 | 시작 → 목표 |
| 목표 레벨 | 선택값 echo |

# 6️⃣ 습던 · 레벨업 티켓 분기

- 습던으로 **레벨업이 발생하면** 해당 레벨업에서는 **티켓 충전 없음** (`shouldRefillTickets`가 `habit`일 때 항상 false).
- **레벨업 티켓 사용 ON**: 습던 1회가 레벨업을 유발할 예정이면 그 회차는 **테라 1판으로 대체**해 충전을 받는다.
- **레벨업 티켓 사용 OFF**: 습던 레벨업 허용(충전 없음), 티켓작 비활성.

# 7️⃣ 이벤트 기반 시뮬레이션

## 🔹 상태 객체

```js
{
  level: number,
  xp: number,
  tickets: number,        // 무한 풀: cost 지불 시 감소하지 않거나, 항상 충분히 보충
  totalTicketsSpent: number,
  totalEntriesSpent: number,
  levelUpCount: number,
  day: number,
}
```

**티켓 무한 가정 구현 예**: `totalTicketsSpent += cost` 만 하고 `tickets`는 cap 충전 로직에만 사용하거나, spend 후에도 `Infinity` treat.

## 🔹 핵심 루프

```text
while (level < targetLevel):
  day++
  // direct: DAY_ACTIVITY_ORDER + 일일 cap
  // preset: single activity until target (no daily cap)
  for each run:
      totalTicketsSpent += ticketCost
      totalEntriesSpent += entryCost
      applyXp(...)
      on levelUp: refill (rules) → if useLevelUpTickets: burn on terra first (inner loop)
  // min/max tracks: pvp day xp low/high two passes or bracket simulation
```

## 🔹 `shouldRefillTickets`

```js
function shouldRefillTickets(newLevel, activity) {
  if (activity === 'habit') return false;
  if (newLevel >= 20) return true;
  if (newLevel <= 19 && newLevel % 3 === 0) return true;
  return false;
}
```

# 9️⃣ 티켓작 (부캐 + 본캐 동시 테라)

```text
alt = { level: 1, xp: 0, tickets: 0 }
spent = 0
refillSum = 0
while alt.level < endLevel and main.level < target:
    // 한 판에 부캐·본캐 함께 입장
    spent += 10
    main.totalTicketsSpent += 10
    alt += 50 XP  (레벨업 시 부캐 충전 → refillSum)
    main += 50 XP (레벨업 시 본캐 충전 → 즉시 테라 재소비 가능)
netTickets = refillSum - spent
if netTickets > 0: main.tickets += netTickets → burn on terra
```

- 티켓작 테라 판은 **부캐 육성 전용 판이 아니라**, 본캐도 같은 판에서 경험치를 받는다.
- **netTickets > 0** 일 때만 남는 회수분을 본캐 티켓 풀에 합류 (레벨업 티켓 사용 ON).
- **netTickets <= 0** 이면 해당 사이클은 **손해** — UI에서 종료 레벨 낮추라는 힌트 가능(선택).

# ✅ 핵심 포인트

* **티켓·입장권 무한**, **하루 입력 횟수**가 일과량을 정의.
* **프리셋** = 단일 콘텐츠 **목표까지 무제한 투입**.
* **1vs1·고블린** = **범위**; 고블린 수 **`floor(pvp/50*5)`**.
* **고블린 XP·소요일** = **최소~최대**, 평균 아님.
* **티켓작** = 부캐 Lv1 + **본캐 동시 테라**, **순 회수 = 부캐 충전합 − 소비합**.
* **즉시 티켓 사용** 우선 **테라**.
* **룬던** = **300 XP**/판.
