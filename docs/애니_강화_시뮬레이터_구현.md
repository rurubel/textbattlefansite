# 애니 강화 시뮬레이터 구현 요약

## 목표
- 0강부터 30강까지 강화 과정을 시뮬레이션한다.
- 일반 강화/집중 강화 2가지 모드를 지원한다.
- 완료 시 최종 30강 결과와 시도 통계를 출력한다.

## 핵심 규칙
- 강화 단계 범위: `0 ~ 30`
- 결과 3종: `성공`, `실패`, `하락`
  - 성공: 단계 +1, 옵션 슬롯 1칸 추가
  - 실패: 변화 없음
  - 하락: 단계 -1, 가장 최근에 추가된 슬롯 1칸 제거(LIFO)
- 옵션 종류: `atk`, `spd`, `crit`, `def`, `hp`
- 옵션별 슬롯 최대: `20칸`
- 슬롯 수치 값은 `logic/probability.js`의 `GRADE_VALUES`를 사용

## 옵션 선택 규칙
### 일반 강화
- 성공 시 5개 옵션 중 랜덤 1개 선택
- 단, 20칸 가득 찬 옵션은 후보에서 제외

### 집중 강화
- 시작 시 집중 옵션 1개를 선택
- 성공 시:
  - 선택 옵션 40%
  - 나머지 옵션 60% (사용 가능한 다른 옵션들에서 균등 랜덤)
- 선택 옵션이 이미 20칸이면 일반 랜덤 선택처럼 처리

### 곡괭이 (자동)
- 체크 시 **곡괭이 발동 옵션**을 최대 **3개**까지 지정한다.
- 강화 **성공**으로 지정한 옵션 중 하나에 칸이 채워지면, 곡괭이로 즉시 되돌린다.
- 되돌림은 **하락과 동일**: 단계 -1, 히스토리에서 마지막 슬롯 제거(LIFO).
- 30강 도달 시 **곡괭이 사용 횟수**(`pickaxeUsed`)를 함께 출력한다.
- 집중 강화 **강화 횟수**(`focusHit`)는 곡괭이로 제거된 성공은 제외한다(남은 칸 기준).

## 등급(grade) 규칙
강화 성공으로 슬롯이 추가될 때, **성공 후 단계** 기준으로 grade를 결정한다.

| 단계 구간 | grade |
|---|---:|
| 1 ~ 9 | 0 |
| 10 ~ 17 | 1 |
| 18 ~ 23 | 2 |
| 24 ~ 27 | 3 |
| 28 ~ 30 | 4 |

## 종료 조건
- 강화 단계가 30에 도달하면 종료

## 출력 항목
- 최종 강화 단계(30)
- 옵션별 강화 칸 수(`atk`, `spd`, `crit`, `def`, `hp`)
- 총 시도 횟수
- 성공/실패/하락 횟수
- 집중 강화 모드일 경우:
  - 선택한 집중 옵션
  - 해당 옵션 강화 횟수
- 곡괭이 자동 사용 시:
  - 곡괭이 발동 옵션 목록(최대 3개)
  - 곡괭이 사용 횟수

# 📄 애니 강화 시뮬레이터 요구사항 정의

## 🎯 목표

0강 → 30강까지 강화 과정을 시뮬레이션하고,
최종 결과 및 통계를 출력하는 프로그램 구현

---

# 1️⃣ 기본 시스템 구조

## 🔹 강화 단계

* 최소: 0강
* 최대: 30강
* 강화 성공 시 +1
* 강화 하락 시 -1
* 강화 실패 시 변화 없음

---

## 🔹 옵션 구조

* 옵션 종류: 5종
  (`atk`, `spd`, `crit`, `def`, `hp`)
* 각 옵션당 슬롯: 20칸
* 총 최대 강화 슬롯: 100칸

---

## 🔹 옵션 값

* `@logic/probability.js`의 `GRADE_VALUES` 사용
* 각 강화 성공 시:

  * 현재 단계에 따른 **등급(grade)** 결정
  * 해당 옵션에 **1칸 추가 (value는 grade 기준)**

---

# 2️⃣ 강화 결과 로직

강화 시도 결과는 3가지:

| 결과 | 설명                    |
| -- | --------------------- |
| 성공 | 강화 단계 +1, 옵션 슬롯 1칸 추가 |
| 실패 | 아무 변화 없음              |
| 하락 | 강화 단계 -1, 마지막 슬롯 제거   |

---

## 🔹 하락 처리 규칙

* 가장 최근에 추가된 옵션 슬롯 1개 제거
* (👉 FIFO ❌ / LIFO 방식 = 스택 구조)

---

# 3️⃣ 옵션 증가 로직

## 🔹 기본 (집중 강화 없음)

* 5개 옵션 중 랜덤 선택
* 단, **20칸 꽉 찬 옵션 제외**

---

## 🔹 집중 강화 (옵션 선택 시)

* 강화 성공 시:

  * 선택한 옵션: 40%
  * 나머지 4개 옵션: 60% (균등 분배)

### ⚠️ 단, 선택 옵션이 20칸 가득 찬 경우

* 일반 랜덤처럼 처리 (5번 규칙 적용)

---

# 4️⃣ 강화 확률 테이블

각 단계별 확률:

```text
단계: 성공 / 실패 / 하락
0: 75 / 25 / 0
1: 75 / 25 / 0
2: 74 / 24 / 2
...
29: 27 / 46 / 27
```

👉 구현 시:

```js
PROB_TABLE[level] = {
  success: number,
  fail: number,
  down: number
}
```

# 7️⃣ 종료 조건

# 8️⃣ 출력 결과

## 🔹 최종 결과

### 1. 옵션 상태

* 각 옵션별 강화 횟수 (슬롯 수)
* 또는 전체 배열 출력 가능

---

### 2. 통계

| 항목      | 내용         |
| ------- | ---------- |
| 총 시도 횟수 | 전체 강화 시도 수 |
| 성공 횟수   | 성공 횟수      |
| 실패 횟수   | 실패 횟수      |
| 하락 횟수   | 하락 횟수      |

---

### 3. 집중 강화 추가 정보 (선택 시)

| 항목          | 내용        |
| ----------- | --------- |
| 집중 옵션       | 선택한 옵션    |
| 해당 옵션 강화 횟수 | 몇 번 강화됐는지 |

# 9️⃣ 내부 데이터 구조 (권장)

## 🔹 상태 객체

```js
{
  level: number,
  subs: {
    atk: [],
    spd: [],
    crit: [],
    def: [],
    hp: []
  },
  history: [] // { type, grade, option }
}
```

---

## 🔹 통계 객체

```js
{
  total: number,
  success: number,
  fail: number,
  down: number,
  focusHit: number // 집중 강화 성공 시 카운트
}
```

---

# 🔟 핵심 로직 흐름

```text
while (level < 30)
  → 확률 테이블로 결과 결정

  → 성공:
      level++
      → 옵션 선택
      → grade 계산
      → 슬롯 추가
      → history push

  → 실패:
      nothing

  → 하락:
      level--
      → history pop
      → 해당 옵션 슬롯 제거

  → 통계 누적
```

# ✅ 핵심 포인트 요약

* 강화는 **확률 기반 상태 머신**
* 옵션은 **슬롯 기반 누적 구조**
* 하락은 **스택(pop) 방식**
* 집중 강화는 **확률 분기**
* 등급은 **레벨 구간 기반**
